# nvim

Clone this repo to `~/.config/nvim`:

```sh
git clone https://github.com/SkylarWapato/nvim.git ~/.config/nvim
```

On macOS, run `scripts/init-osx.sh` to install everything else this config needs.

## Notes

`nvim -c Notes` opens a blank markdown buffer in `~/notes`. Saving it names the file after line 1 (e.g. `# My Cool Note` becomes `my-cool-note.md`).
